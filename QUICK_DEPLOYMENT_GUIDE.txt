STEP 3: RENDER DEPLOYMENT (5 minutes)
================================================================================

1. Go to https://render.com
2. Sign in with GitHub
3. Click "New +" → "Web Service"
4. Select: banking-credit-risk-calculator
5. Fill in:

   Name: banking-credit-risk
   Region: Singapore
   Branch: main
   Build Cmd: pip install -r requirements.txt
   Start Cmd: gunicorn app:app
   Instance: Free

6. Add Environment Variables:

   FLASK_ENV = production
   SECRET_KEY = bk8xP2mQnR7vLcW3jdA5X (any random string)

7. Click "Create Web Service"

Result: Render starts building and deploying

================================================================================
IMPORTANT NOTES
================================================================================

Cold Start:
- First visit after 15 min of inactivity takes 30-50 seconds
- This is normal on Render's free tier
- All subsequent visits are instant
- Share this note with users if needed

For Production Data:
- Current model uses synthetic demo data
- To use real data:
  1. Collect 3-5 years of historical borrower data
  2. Run: python train_pd_model.py (it will load your data)
  3. Push new model to GitHub
  4. Render redeploys automatically

Troubleshooting:
- Check Render dashboard → Logs tab if anything fails
- Make sure runtime.txt has exactly: python-3.12.0
- Make sure .gitignore excludes venv/ but includes ml_models/
