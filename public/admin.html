📁 Training Data Sources

Primary: bank_loan_metrics (customer-level, one row per loan) — includes behavioral features derived from transaction history (EMI miss ratio, income volatility, etc). Used by default on every "Train Now" run.
Optional: enriched_transactions table in bank.db — transaction-level (56K+ rows, many per loan). Not used by default: adds row-count without a real accuracy gain once loan-group leakage is accounted for.
Supplementary: CSV files placed in data/training/ — merged with the DB rows and archived after a successful run.

🧠 Global SHAP — signal vs. noise

SHAP is model-agnostic, but the algorithm it runs under differs by architecture - this always states which model type and scope it ran against. A synthetic random __noise__ feature is trained in alongside the real ones (same architecture + hyperparameters as the selected model, refit on a fresh sample): any real feature whose ratio to that noise column is near 1.0x is statistically indistinguishable from a coin flip for this model.
